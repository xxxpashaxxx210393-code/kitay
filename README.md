# 🚀 ИНСТРУКЦИЯ ПО ЗАПУСКУ И ДЕПЛОЮ «КАРГО-КОНТРОЛЬ 🇨🇳 ➔ 🇧🇾» В ИНТЕРНЕТ

Поздравляем! Ваш трекер заказов из Китая полностью готов, оптимизирован и протестирован. Ниже приведена подробная, пошаговая инструкция, как перенести это приложение из песочницы на постоянный хостинг, чтобы вы могли заходить в него с мобильного телефона и компьютера в любое время дня и ночи абсолютно бесплатно.

---

## 📌 ШАГ 1. Как скачать этот проект к себе на компьютер

В интерфейсе данной среды разработки (в правом верхнем углу или в меню файлового менеджера) нажмите кнопку **Download ZIP** (Скачать проект как архив) или клонируйте репозиторий.

Распакуйте полученный архив в любую удобную папку у себя на компьютере.

---

## 📌 ШАГ 2. Создание бесплатной базы данных PostgreSQL

Ваше приложение хранит всю информацию о товарах, трек-номерах, ценах и получателях в базе данных PostgreSQL. Для работы в интернете создадим бесплатную облачную базу данных:

1. Перейдите на сайт **[Neon.tech](https://neon.tech/)** (или [Supabase.com](https://supabase.com/)) и зарегистрируйтесь через почту или GitHub.
2. Создайте новый бесплатный проект (например, `cargo-db`). В качестве региона выберите наиболее близкий к вам (например, **Frankfurt** или **Europe**).
3. После создания проекта Neon покажет вам строку подключения (Connection String). Она выглядит примерно так:
   ```env
   DATABASE_URL="postgresql://neondb_owner:AbCdEf1234@ep-cool-cloud-123456.eu-central-1.aws.neon.tech/neondb?sslmode=require"
   ```
4. **Скопируйте эту строку!** Она понадобится нам на следующем шаге.

---

## 📌 ШАГ 3. Создание репозитория на GitHub

Чтобы выгрузить проект на бесплатный хостинг, нам нужно сохранить код на вашем аккаунте GitHub:

1. Зарегистрируйтесь на **[GitHub.com](https://github.com/)** и создайте новый репозиторий.
2. Сделайте его **Private** (приватным), чтобы ваши личные трек-номера и цены не видел никто посторонний. Назовите его, например, `china-cargo-tracker`.
3. Загрузите файлы вашего распакованного проекта в этот репозиторий. Сделать это можно прямо через интерфейс сайта GitHub (кнопка **Upload files**) или через командную строку Git:
   ```bash
   git init
   git add .
   git commit -m "initial commit of china cargo tracker"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/china-cargo-tracker.git
   git push -u origin main
   ```

## 📌 ШАГ 4. Деплой сайта на хостинг Vercel (Бесплатно навсегда)

**Vercel** — это лучшая мировая платформа для запуска Next.js приложений. Она берет на себя сборку, оптимизацию картинок и дает вам бесплатный домен с SSL-сертификатом безопасности (https://).

1. Перейдите на сайт **[Vercel.com](https://vercel.com/)** и выберите авторизацию через **GitHub** (это свяжет ваши аккаунты).
2. На главной панели Vercel нажмите кнопку **«Add New...»** -> **«Project»**.
3. В появившемся списке репозиториев найдите ваш `china-cargo-tracker` и нажмите кнопку **«Import»**.
4. В настройках проекта раскройте вкладку **«Environment Variables»** (Переменные окружения) и добавьте переменную для подключения вашей базы данных:
   * **Key (Имя)**: `DATABASE_URL`
   * **Value (Значение)**: Вставьте ту самую скопированную строку подключения PostgreSQL из **Шага 2** (начинается с `postgresql://`).
5. Нажмите кнопку **«Deploy»** (Запустить)!

🎉 Через 1–2 минуты сборка завершится, и Vercel выдаст вам личную безопасную веб-ссылку (например, `https://china-cargo-tracker.vercel.app`). Откройте её на телефоне или компьютере — трекер полностью работает!

## 📌 ШАГ 5. Первоначальный запуск таблиц (Миграция БД)

При самом первом запуске приложения ваша новая база данных будет пустой. Чтобы автоматически создать в ней все необходимые таблицы (orders) для учета посылок, выполните одну простую команду на своем компьютере в папке проекта:

1. Откройте терминал/командную строку в папке с проектом.
2. Установите зависимости одной командой:
   ```bash
   npm install
   ```
3. Создайте в корне проекта файл `.env` и вставьте туда скопированную строку `DATABASE_URL` от Neon.tech.
4. Выполните команду синхронизации таблиц:
   ```bash
   npx drizzle-kit push
   ```
5. Всё готово! База данных моментально создаст таблицы. Теперь, когда вы откроете сайт по вашей ссылке с Vercel, приложение автоматически подгрузит демо-товары, и вы сможете полноценно вести свой бизнес.

## 💡 Особенности проекта, которые сделают вашу работу легкой:
* **Интерактивные Вкладки**: «Активные товары» и «Архив» разделены, чтобы выданные заказы автоматически скрывались с глаз и не путали вас при сборе новых посылок.
* **Посекундный Excel-Импорт**: Просто перетащите вашу таблицу в диалоговое окно импорта. Система автоматически распознает заголовки (даже если они написаны по-разному!) и загрузит все товары в базу данных за один клик с полосой прогресса.
* **Групповое изменение статусов**: Вставьте список трек-номеров через запятую или с новой строки, выберите нужный статус и нажмите «Применить ко всем».
* **Курс по умолчанию**: Вы можете в любой момент сменить обменный курс рубля к юаню одной кнопкой в углу экрана, и все цены в рублях мгновенно пересчитаются по новым значениям.
